## Platform bootstrap

The chicken-and-egg is by design: `setPlatformOwner` requires an existing platform owner, so the *first* platform owner must be provisioned out-of-band (Task 17 Step 2 covers this — `npx convex run` or dashboard patch on `userProfiles.platformRole`).

The test exercises this directly via `t.run(async (q) => { await q.db.patch(aliceId, { platformRole: "platform_owner" }); })` — `convex-test` 0.0.55's `t.run` exposes the mock mutation ctx (verified in `node_modules/convex-test/dist/index.d.ts:45` and already used this way in `convex-test/members.test.ts`).

After the bootstrap patch, Alice can call `api.platform.listAllOrgs` and see the org she created.
